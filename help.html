❓ Python install karte waqt "python not recognized" error aa raha hai?

+
Install karte waqt "Add Python to PATH" wale checkbox pe tick nahi kiya hoga. Uninstall karke dobara install kar aur is baar checkbox tick zaroor karna! ✅

❓ pip install command kaam nahi kar raha?

+
Terminal mein ye try kar:
python -m pip install --upgrade pip
Phir apna module install karna try kar!

❓ print statement mein error aa raha hai?

+
Check kar:
✅ Brackets sahi hain: print("Hello")
✅ Quotes sahi hain (" ya ')
✅ Spelling: print hai, prit nahi
✅ Small letters mein hai

❓ Module import karne pe error milta hai?

+
External module hai to pehle install kar:
pip install module_name
Phir import kar. Built-in modules (os, random) directly import ho jate hain!

❓ Python file kaise run karu?

+
1. File save kar .py extension ke saath (jaise hello.py)
2. Terminal khol
3. Us folder mein ja jahan file hai
4. Type kar: python filename.py
5. Enter dabao — output aa jayega! 🎉

❓ REPL mode se bahar kaise aayein?

+
3 tarike:
1. Type kar: exit()
2. Ya: quit()
3. Ya: Ctrl + Z phir Enter (Windows)
4. Ya: Ctrl + D (Mac/Linux)

❓ Quiz mein galat answer aaya, kya karu?

+
Tension mat le! 😊
1. Notes dobara padh
2. Explanation dhyan se dekh (galat answer ke baad aati hai)
3. "Retry" button dabake dobara try kar
4. Practice se sab ho jayega! 💪
