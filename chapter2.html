💬 Comments Kya Hote Hain?

Comments woh lines hoti hain jo Python IGNORE karta hai — run nahi karta.

Comments ka use kyu karte hain?

  • 📝 Code samjhaane ke liye
  • 👤 Author ka naam likhne ke liye
  • 📅 Date mention karne ke liye
  • 💡 Notes add karne ke liye
💡 Example: Jaise Prashant apni notebook mein margin pe extra notes likhta hai jo exam mein count nahi hoti — waise hi comments code mein hoti hain, computer unko ignore karta hai!

1️⃣ Single Line Comments

Ek line ka comment likhne ke liye # symbol use karo:

Python
# Ye ek single line comment hai
print("Hello World")  # Ye bhi comment hai

Sab kuch jo # ke baad hoga wo comment ban jayega!

2️⃣ Multi-Line Comments

Bahut saari lines ka comment likhne ke liye triple quotes use karo:

Python
"""
Ye ek multi-line comment hai
Author: Shyam
Date: 2025
"""
print("Hello")
💡 Example: Jaise Aham ek chhoti si note likhta hai (#), aur Nishant pura paragraph likhta hai ("""...""") — dono valid hain!

📦 Variables Kya Hote Hain?

Variable ek DABBA hai jismein tum koi value store kar sakte ho.

Python
a = 30       # variable = value ko store karta hai
b = "Shyam"  # keyword = reserved words
c = 71.22   # identifier = variable/function ka naam
💡 Example: Jaise Aditya ke ghar mein alag alag dabbe hain — ek mein cheeni, ek mein namak, ek mein daal. Waise hi variables alag alag values store karte hain!

📏 Variable Name Rules

Variable ka naam rakhne ke kuch rules hain:

✅
Alphabets, digits, underscore use kar sakte ho
Example: shyam, one8, seven_
✅
Alphabet ya underscore se start ho sakta hai
Example: shyam, _seven
❌
Digit se start NAHI ho sakta
Wrong: 1shyam, 8one
❌
Space allowed nahi hai
Wrong: my name (Use: my_name)
💡 Valid Examples: shyam, prashant, one8, seven_, _seven, my_age
Invalid: 1shyam, my name, @shyam

➕ Operators in Python

Operators wo symbols hain jo kuch operation perform karte hain.

4 types ke operators hain:

➕ Arithmetic Operators

Math ke liye

+   -   *   /

📝 Assignment Operators

Value assign karne ke liye

=   +=   -=

🔍 Comparison Operators

Compare karne ke liye

==   >   <   !=

🧠 Logical Operators

Logic ke liye

and   or   not

💻 Operators Examples

Arithmetic
a = 10 + 5   # 15
b = 20 - 8   # 12
c = 4 * 3    # 12
d = 100 / 4  # 25.0
Comparison
x = 10 == 10  # True
y = 5 > 3    # True
z = 7 != 7   # False
Logical
p = True and False  # False
q = True or False   # True
r = not True       # False
