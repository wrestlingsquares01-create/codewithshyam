hello.py

Terminal mein type karo:

Terminal

Module matlab readymade code ki file jo koi aur likh chuka hai. Hum import karke use kar lete hain.

📥 Pip Kya Hai?

Pip Python ka package manager hai — modules install karta hai.

Terminal
pip install flask
💡 Example: Jaise Aditya Play Store se apps install karta hai, waise hi Pip se Python modules install hote hain!

📂 Types of Modules

✅ Built-in Modules

Python ke saath pehle se aate hain

Examples: os, random

📥 External Modules

Pip se install karne padte hain

Examples: flask, tensorflow

💡 Yaad rakh:
Built-in = Phone mein pehle se jo apps hoti hain
External = Play Store se download karta hai

🧮 Python as Calculator (REPL)

Terminal mein python type karo — REPL mode khul jayega:

REPL Mode
>>> 10 + 20
30

>>> 5 * 8
40

>>> 100 / 4
25.0

REPL ka full form:

  • R = Read — Input padhta hai
  • E = Evaluate — Solve karta hai
  • P = Print — Answer dikhata hai
  • L = Loop — Dubara ready
💡 Example: Jaise Babita Mam class mein bacchon ke marks jodne ke liye calculator use karti hain, waise hi Python ka REPL mode seedha calculator jaisa kaam karta hai! 👩‍🏫
